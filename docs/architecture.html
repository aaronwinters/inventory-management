Architecture Overview

Factory Inventory Management System

A demo full-stack dashboard: a Vue 3 single-page app talks to a stateless FastAPI service, which serves and filters sample data loaded from JSON files into memory at startup. There is no database and no authentication.

Data flow: changing a filter

The core interaction. Filters live in one shared composable, so every view sees the same selection.

  1. User picks a filter FilterBar.vue

    Four dropdowns (Time Period, Warehouse, Category, Order Status) are bound with v-model to refs in useFilters.

  2. Shared state updates composables/useFilters.js

    The refs are declared at module scope, so every component calling useFilters() gets the same instances.

  3. View reacts views/*.vue

    Each view watches the filter refs it cares about and calls its load function, which reads getCurrentFilters().

  4. Request is built api.js

    Values of 'all' are dropped; the rest become query params, e.g. /api/orders?warehouse=Tokyo&month=2025-03.

  5. Server filters in memory server/main.py

    List comprehensions over the loaded data. Category and status match case-insensitively; month is a substring match on order_date.

  6. Response validated and returned Pydantic

    Endpoints with a response_model are validated and serialized to JSON.

  7. UI recomputes computed()

    Raw responses go into refs; KPIs, chart series and table rows are computed, then formatted per locale (USD or JPY at a fixed 150 rate).

Things to know

Mismatches found while reading the code. Worth knowing before you build on it.

Missing API
api.js calls endpoints the server does not have

getTasks, createTask, deleteTask, toggleTask, createPurchaseOrder and getPurchaseOrderByBacklogItem target /api/tasks and /api/purchase-orders, which would return 404. The PurchaseOrder models exist in main.py but no routes use them.

Missing component
Dashboard renders <PurchaseOrderModal> without importing it

No such file exists, so Vue logs a resolve warning and the modal never appears.

Unrouted
Backlog.vue is not registered in the router

Backlog data is only visible through the Dashboard panel.

Inconsistent
Reports.vue bypasses api.js

It calls axios with a hardcoded http://localhost:8001 URL instead of going through the shared client.

Behavior
Some filter semantics are looser than they look

The server accepts quarter keys (Q1-2025) but FilterBar only sends months. Month matching is a substring test on the date string. The Dashboard backlog count ignores all filters.
